# AiDoc.Cli

Консольное приложение для генерации документации AIDoc.

## Описание

CLI приложение предоставляет удобный интерфейс командной строки для:
- Генерации документации на основе исходного кода
- Обновления существующей документации

## Требования

- .NET 8.0+
- Git
- Доступ к Python API серверу

## Установка

```bash
# Клонирование репозитория
git clone https://github.com/SergeiKrivko/aidoc.git
cd aidoc

# Сборка CLI
dotnet build AiDoc.Cli
```

## Использование

### Команды

#### Генерация документации
```bash
dotnet run --project AiDoc.Cli -- generate --source-path ./myproject --name MyApp
```

#### Обновление документации
```bash
dotnet run --project AiDoc.Cli -- update --source-path ./myproject --name MyApp
```

### Параметры командной строки

#### Общие параметры
- `--source-path` - путь к исходному коду проекта (по умолчанию: текущая директория)
- `--doc-path` - путь для сохранения документации (по умолчанию: `{source-path}/docs`)
- `--name` - название проекта (по умолчанию: имя папки исходного кода)
- `--api-url` - URL Python API сервера (по умолчанию: https://aidoc-api.nachert.art)

#### Примеры использования

```bash
# Генерация документации для текущего проекта
dotnet run --project AiDoc.Cli -- generate

# Генерация с указанием путей
dotnet run --project AiDoc.Cli -- generate \
  --source-path /path/to/source \
  --doc-path /path/to/docs \
  --name MyProject

# Использование кастомного API сервера
dotnet run --project AiDoc.Cli -- generate \
  --source-path ./myproject \
  --api-url http://my-api-server:8000
```

## Конфигурация

### Переменные окружения

- `API_URL` - URL Python API сервера (по умолчанию: https://aidoc-api.nachert.art)

### Пример настройки

```bash
# Установка переменной окружения
export API_URL="http://my-api-server:8000"

# Или для Windows
set API_URL=http://my-api-server:8000
```

## Архитектура

CLI использует компоненты из Core:

- **AiDoc.Core.ApiClient** - клиент для работы с Python API
- **AiDoc.Core.Models** - доменные модели
- **AiDoc.Core.Abstractions** - интерфейсы
- **AiDoc.Git** - утилиты для работы с Git

### Основные компоненты

#### DocumentProcessor
Основной класс для обработки документации:
- Создание запросов на генерацию
- Управление процессом генерации
- Обработка результатов

#### LocalSourceStorage
Хранилище исходного кода:
- Сканирование файлов проекта
- Игнорирование ненужных файлов (bin, obj, .git)
- Создание ZIP архивов для отправки

#### LocalDocumentationStorage
Хранилище документации:
- Управление файлами документации
- Сохранение метаданных
- Отслеживание изменений

## Рабочий процесс

### 1. Генерация документации
1. Сканирование исходного кода
2. Создание ZIP архива с исходными файлами
3. Отправка запроса на генерацию в Python API
4. Ожидание завершения с поллингом
5. Сохранение результата

### 2. Обновление документации
1. Анализ изменений в исходном коде
2. Создание обновленного запроса
3. Генерация новой документации
4. Обновление существующих файлов

## Интеграция с Git

CLI автоматически:
- Определяет текущий commit hash
- Игнорирует файлы из .gitignore
- Отслеживает изменения в исходном коде
- Сохраняет информацию о версии документации

## Обработка ошибок

### Типичные ошибки и решения

#### API сервер недоступен
```
Ошибка: Failed to connect to API server
```
**Решение**: Убедитесь, что Python API сервер запущен и доступен по указанному URL.

#### Таймаут генерации
```
Ошибка: Documentation generation timed out
```
**Решение**: Увеличьте таймаут или проверьте производительность API сервера.

#### Недостаточно места на диске
```
Ошибка: Insufficient disk space
```
**Решение**: Освободите место на диске или измените путь для документации.
